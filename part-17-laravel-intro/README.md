## ขั้นตอนที่ 421: Laravel คืออะไร?

Laravel คือ PHP Framework ที่ได้รับความนิยมสูงสุดในโลก สร้างโดย Taylor Otwell

### ทำไมต้องใช้ Laravel?
- **Eloquent ORM** - Database ที่ใช้งานง่าย
- **Blade Templating** - Template Engine ที่ทรงพลัง
- **Artisan CLI** - Command Line Tools
- **Built-in Auth** - Authentication สำเร็จรูป
- **Queue System** - Background Jobs
- **Testing** - PHPUnit integration
- **Ecosystem** - Horizon, Telescope, Forge, Vapor

### Laravel Versions
- Laravel 10 (PHP 8.1+)
- **Laravel 11 (PHP 8.2+) - Current**
- Laravel 12 (PHP 8.2+) - Upcoming

## ขั้นตอนที่ 422: การติดตั้ง Laravel

```bash
# Prerequisites
php -v       # PHP 8.2+
composer -v  # Composer 2.x
node -v      # Node.js 18+ (สำหรับ Vite)
mysql -v     # MySQL 8.0+

# ติดตั้ง Laravel Installer
composer global require laravel/installer

# สร้าง Project ใหม่
laravel new my-project

# หรือใช้ Composer
composer create-project laravel/laravel my-project

# เลือก Starter Kit (ถ้าใช้ Laravel Installer)
# - No starter kit
# - Laravel Breeze (simple auth)
# - Laravel Jetstream (full-featured auth)

# เข้าไปใน project
cd my-project

# Start Development Server
php artisan serve
# หรือ
php artisan serve --port=8080

# ใช้ Vite สำหรับ Frontend
npm install
npm run dev
```

## ขั้นตอนที่ 426: Service Container

```php
<?php
// Service Container คือ IoC Container
// จัดการ Dependencies ให้อัตโนมัติ

// === Binding ===
// ใน AppServiceProvider หรือ Custom ServiceProvider

use App\Services\PaymentGateway;
use App\Services\StripeGateway;

// Simple Binding
app()->bind(PaymentGateway::class, StripeGateway::class);

// Closure Binding
app()->bind('mailer', function ($app) {
    return new Mailer($app->make('config')['mail']);
});

// Singleton - สร้างครั้งเดียว
app()->singleton(PaymentGateway::class, function ($app) {
    return new StripeGateway(config('services.stripe.key'));
});

// Instance Binding
$gateway = new StripeGateway('test_key');
app()->instance(PaymentGateway::class, $gateway);

// === Resolving ===
$gateway = app(PaymentGateway::class);
$gateway = app()->make(PaymentGateway::class);
$gateway = resolve(PaymentGateway::class);

// Auto-Resolution (Type Hinting)
class OrderController extends Controller {
    public function __construct(
        private PaymentGateway $payment  // Auto-injected!
    ) {}
    
    public function charge(Request $request): JsonResponse {
        $result = $this->payment->charge(
            $request->amount,
            $request->token
        );
        return response()->json($result);
    }
}

// Service Provider
namespace App\Providers;

use Illuminate\Support\ServiceProvider;

class PaymentServiceProvider extends ServiceProvider {
    public function register(): void {
        $this->app->singleton(PaymentGateway::class, function ($app) {
            $driver = config('payment.driver', 'stripe');
            return match($driver) {
                'stripe' => new StripeGateway(config('payment.stripe.key')),
                'paypal' => new PayPalGateway(config('payment.paypal.client_id')),
                default => throw new \InvalidArgumentException("Unknown driver: $driver")
            };
        });
    }
    
    public function boot(): void {
        // Boot after all services registered
    }
}
```
